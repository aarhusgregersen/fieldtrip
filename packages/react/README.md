# @fieldtripjs/react

Headless React bindings for [@fieldtripjs/core](https://www.npmjs.com/package/@fieldtripjs/core): `useFlow` and `createFlowContext`. State and navigation from fieldtrip, UI from you.

```sh
pnpm add @fieldtripjs/core @fieldtripjs/react
```

See the [main README](https://github.com/aarhusgregersen/fieldtrip#readme) for docs.
