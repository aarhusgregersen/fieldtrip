# @fieldtrip/react

Headless React bindings for [@fieldtrip/core](https://www.npmjs.com/package/@fieldtrip/core): `useFlow` and `createFlowContext`. State and navigation from fieldtrip, UI from you.

```sh
pnpm add @fieldtrip/core @fieldtrip/react
```

See the [main README](https://github.com/aarhusgregersen/fieldtrip#readme) for docs.
