# @fieldtrip/core

State machines for human input: typed, testable, analyzable multi-step flows. Zero dependencies; fields are any [Standard Schema](https://standardschema.dev) (Zod, Valibot, ArkType…).

```sh
pnpm add @fieldtrip/core
```

See the [main README](https://github.com/aarhusgregersen/fieldtrip#readme) for docs.
